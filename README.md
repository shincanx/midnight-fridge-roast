One-line roast of a smart fridge that refuses to open after midnight, built for the [Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) bounty on [make.fun](https://make.fun) ($2 in USDC).

## The entry

> My fridge refuses to open after midnight, as if my leftovers filed a restraining order against me.

## Run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (and prints it). Deterministic: no input, no network, no randomness.
